# ShopScout

A weekly competitor digest for small Instagram and TikTok sellers.

You name the pages you watch. Each week ShopScout pulls their recent posts, spots new products, price changes and promos, and sends you a short summary. It pays for the data per call over x402 on Celo mainnet through the [buy](https://usebuy.ai) gateway, so the seller never touches crypto.

Built for the Agents on Open Rails Hackathon (Build with buy track).

Status: in progress.
